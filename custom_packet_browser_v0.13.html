SNR uses signal RMS / noise RMS over all audio samples at 48 kHz (broadband noise, 0–24 kHz), matching the Python RMS method. It is not an in-band RF SNR or a receiver sensitivity measurement. With clipping off, signal and noise are scaled together to avoid clipping without changing SNR. *Measured SNR is before optional saturation. Each trial uses a different seed; a pass requires the exact transmitted bytes and valid CRC. More trials and longer packets make the test more demanding. AWGN does not reproduce HF fading, tuning error, or clock drift. Live decoding pauses during a test and resumes afterward. Decoding uses a Web Worker to keep the interface responsive. Microphone capture prefers AudioWorklet; compatibility capture is used if the browser blocks worklet loading. RX status shows the active capture method.

Decoder diagnostics

v0.13 uses transition-driven PLL clock recovery adapted from the Python decoder, with eight initial phases and both NRZI polarities. It adjusts sampling phase and clock rate continuously. A faster acquisition loop is tried if the normal hypotheses recover no CRC-valid packets. Fixed-phase decoding remains as a fallback. CRC-valid packets from all timing hypotheses are combined without duplicates. The CRC checkbox controls terminal display; RF/iGate forwarding still requires valid CRCs.

Digipeater / RF routing

Enabling the digipeater also arms browser audio TX. WIDE1-1 and WIDE2/WIDE3 are enabled by default. Routes only CRC-good live microphone frames. Direct repeating handles the first unused path address. WIDE aliases insert this station and decrement the remaining hops. Self-tests and audio files never trigger forwarding. TX uses your default audio output and requires a radio VOX/interface. Audio TX starts immediately. A new transmission replaces any packet still playing; there is no buffering or channel-busy delay.
